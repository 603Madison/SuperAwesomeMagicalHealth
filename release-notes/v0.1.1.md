## SuperAwesomeMagicalHealth 0.1.1

**Signing in with Authentik works with more provider setups.** The server sends its client
secret the way the provider asks for it (in the header or in the form), and tries the other way
once if the first is refused. A client ID or secret pasted with a stray space or newline still
works. When the provider still says no, the message says what to fix: no client secret saved yet
(paste it in Admin › Sign-in, or set `SAMH_OIDC_CLIENT_SECRET`), or one that doesn't match the
provider's.

Also in this version:

- Habits count days ticked before the habit was made.
- Viewing someone's shared health: switching between their data and yours reloads the page for
  the right person.
- The F-Droid repository: add https://603madison.github.io/SuperAwesomeMagicalHealth/ to F-Droid.
