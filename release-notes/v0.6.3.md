## SuperAwesomeMagicalHealth 0.6.3: security updates

No new features: this release brings the libraries the server, web app and phone app are built on
up to versions with known security holes fixed.

- **The server's web layer** (Netty 4.2.20, under Ktor) fixes a critical TLS bypass and several
  ways a crafted request could slip past checks or tie up the server.
- **The AI assistant's libraries** (Jackson 2.21.8 and OpenTelemetry 1.68.0, under the Anthropic
  SDK) fix ways crafted replies could use up memory or CPU.
- **Logging** (logback 1.5.38) and, in the phone app, **Guava 33.7.2**.
- **The web app's router** (React Router 7.18.5) fixes open redirects.

Update the server and the phone app together.
