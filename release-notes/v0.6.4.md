## SuperAwesomeMagicalHealth 0.6.4: up to date underneath

No new features: everything the server, web app and phone app are built on is now current.

- **Server:** Kotlin 2.4, Ktor 3.6, OkHttp 5, kotlinx-serialization 1.13, SQLite 3.54,
  logback 1.6, PDFBox 3.0.8 (reports), Jakarta Mail (Angus 2.0.5) and TwelveMonkeys 3.15
  (progress photos).
- **Phone app:** Android Gradle Plugin 9, the latest AndroidX (Compose, lifecycle, navigation,
  WorkManager, DataStore, fragments) and OkHttp 5.
- **Web app:** React 19.3, lucide icons 1.x, Vite 8 and TypeScript 7.
- The security fixes from 0.6.3 stay in place.

Update the server and the phone app together.
