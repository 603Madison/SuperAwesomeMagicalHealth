Add it to F-Droid

On your phone, with F-Droid installed, tap the button. F-Droid asks to add the repository; then find SuperAwesomeMagicalHealth and install it.

Add to F-Droid

Or add it by hand

  1. In F-Droid, open Settings › Repositories and tap +.
  2. Scan the QR code above, or paste this address:
https://603madison.github.io/SuperAwesomeMagicalHealth/fdroid/repo?fingerprint=0E7544D531E710F53AA540D01256556AD42A62D7ABDC64CF0424339FFBEBB580

F-Droid checks the repository by its fingerprint, which should be:

0E75 44D5 31E7 10F5 3AA5 40D0 1256 556A D42A 62D7 ABDC 64CF 0424 339F FBEB B580

The app is signed with the same key, so updates from here and from the GitHub releases are the same app.
